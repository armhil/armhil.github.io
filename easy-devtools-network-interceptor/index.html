Easy DevTools – Network Interceptor

Inspect recent network requests, redirect exact URLs, respond with local files, and block requests while testing websites in Chrome.

  • View and filter the last 50 HTTP/HTTPS requests from the active tab.
  • Redirect an exact request URL to another HTTP/HTTPS URL.
  • Respond to an exact request URL with a selected local file (up to 2 MiB) in version 2.1.
  • Block an exact request URL.
  • Keep rules on your device and pause interception with the master switch.

Rules apply to the active tab in the last focused browser window. Chrome-protected pages cannot be intercepted. Version 2.1 local-file responses use the required debugger permission and show Chrome’s debugging banner. Selected file snapshots remain on your device and are exposed as responses to the page you are testing. Custom headers, status codes, and timeouts are not supported.
